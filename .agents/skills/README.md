# 🧠 Skills Especializados de FincaControl

Este directorio contiene las habilidades (*skills*) desarrolladas específicamente para asistir en el diseño, desarrollo, pruebas y mantenimiento del software **FincaControl**.

## Catálogo de Skills Disponibles

| Skill | Directorio | Descripción Principal |
| :--- | :--- | :--- |
| **`fincacontrol-offline-sync`** | [`fincacontrol-offline-sync/SKILL.md`](./fincacontrol-offline-sync/SKILL.md) | Arquitectura *Offline-First*, SQLite local (`animales`, `catalogo_razas`, `sync_queue`), distinción entre `id_numero` e `hierro`, y resolución de conflictos. |
| **`fincacontrol-produccion-ganadera`** | [`fincacontrol-produccion-ganadera/SKILL.md`](./fincacontrol-produccion-ganadera/SKILL.md) | Etapas y clasificación fisiológica bovina en Venezuela (*Becerro/a, Maute/a, Novillo/a, Toro, Vaca parida/escotera/seca*), catálogo extensible de razas, producción de leche y pesaje de carne (GDP/GMD). |
| **`fincacontrol-sanidad-tiempos-retiro`** | [`fincacontrol-sanidad-tiempos-retiro/SKILL.md`](./fincacontrol-sanidad-tiempos-retiro/SKILL.md) | Eventos veterinarios, vacunaciones de ley (INSAI), vademécum y alertas críticas de tiempos de retiro para leche y carne por `ID_Numero`. |
| **`fincacontrol-manejo-reproductivo`** | [`fincacontrol-manejo-reproductivo/SKILL.md`](./fincacontrol-manejo-reproductivo/SKILL.md) | Ciclo reproductivo bovino, validación de estado de preñez exclusivo para hembras, alertas de secado, registro de parto y genealogía materno-filial por Número Identificador (`ID_Numero`). |
| **`fincacontrol-finanzas-costos-directos`** | [`fincacontrol-finanzas-costos-directos/SKILL.md`](./fincacontrol-finanzas-costos-directos/SKILL.md) | Libro de caja operativo, ventas por categoría fisiológica/canal, cálculo de costo unitario por litro de leche y márgenes de rentabilidad. |
